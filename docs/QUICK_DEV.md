# 🚀 Быстрый просмотр изменений

## Самый простой способ (рекомендуется)

```bash
npm run dev
```

Откройте браузер: **http://localhost:5174**

✅ **Hot Reload включен** - все изменения видны автоматически  
✅ **Использует продакшен API** - не нужен локальный backend

---

## Варианты запуска

### 1️⃣ Только Frontend (самый быстрый)
```bash
npm run dev
```
- ✅ Быстрый старт
- ✅ Hot Reload (автоматическое обновление)
- ✅ Использует продакшен API (https://yourdomain.com/api)
- 🌐 http://localhost:5174

### 2️⃣ Frontend + Локальный Backend
```bash
# Терминал 1: Backend
cd backend
python manage.py runserver 8000

# Терминал 2: Frontend
npm run dev
```
- ✅ Полная локальная разработка
- ✅ Можно менять и frontend, и backend
- 🌐 Frontend: http://localhost:5174
- 🌐 Backend: http://localhost:8000/api

### 3️⃣ Frontend + VK Tunnel (для тестирования в VK)
```bash
# Терминал 1: Frontend
npm run dev

# Терминал 2: VK Tunnel
npm run tunnel
```
- ✅ Тестирование в реальном VK приложении
- ✅ Публичный URL для VK
- ⚠️ Требует настройки в VK Developer

## Что происходит при изменении файлов?

Vite автоматически:
1. 🔄 Обнаруживает изменения в файлах
2. ⚡ Компилирует только измененные части
3. 🌐 Обновляет браузер через WebSocket (HMR)
4. 💾 Сохраняет состояние компонентов (если возможно)

**Время обновления: < 100ms** ⚡

## Troubleshooting

### Порт 5174 занят?
Измените порт в `vite.config.js`:
```js
server: {
  port: 3000, // или другой свободный порт
}
```

### Изменения не видны?
1. Проверьте консоль браузера (F12)
2. Перезагрузите страницу (Ctrl+R или Cmd+R)
3. Очистите кэш браузера (Ctrl+Shift+R)

### API не работает?
- Проверьте, что продакшен API доступен: https://yourdomain.com/api/mfos/
- Или запустите локальный backend (вариант 2)
