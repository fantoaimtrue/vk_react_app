# 🔧 Исправление ошибок push-уведомлений

## Проблема
При попытке отправить push-уведомления происходит **69 ошибок** с сообщением:
```
VK_APP_ACCESS_TOKEN не установлен в settings.py
```

## Причина
В файле `.env` отсутствует или не установлен токен доступа VK API (`VK_APP_ACCESS_TOKEN`).

## Решение

### 1. Получите токен доступа VK

Токен можно получить в настройках вашего VK Mini App:
1. Перейдите на https://vk.com/apps?act=manage
2. Выберите ваше приложение
3. Перейдите в раздел "Настройки" → "Работа с API"
4. Скопируйте "Сервисный ключ доступа" (Service Token)

### 2. Добавьте токен в .env файл

Откройте файл `.env` в корне проекта и добавьте строку:

```bash
VK_APP_ACCESS_TOKEN=ваш_токен_здесь
```

**Важно:**
- Токен должен быть на одной строке без пробелов
- Не добавляйте кавычки вокруг токена
- Файл `.env` НЕ должен быть в git (уже в .gitignore)

### 3. Перезапустите backend

После добавления токена перезапустите контейнер backend:

```bash
docker-compose restart backend
```

Или полностью перезапустите все сервисы:

```bash
docker-compose -f docker-compose.yml -f docker-compose.prod.yml restart
```

### 4. Проверьте работу

После перезапуска попробуйте отправить push-уведомление снова через админку Django.

## Проверка токена

Чтобы проверить, что токен установлен правильно, выполните:

```bash
docker-compose exec backend python manage.py shell
```

Затем в Python shell:
```python
from django.conf import settings
token = getattr(settings, 'VK_APP_ACCESS_TOKEN', None)
print('Token present:', bool(token))
print('Token length:', len(token) if token else 0)
```

Если токен установлен, вы увидите:
```
Token present: True
Token length: [длина токена]
```

## Дополнительная информация

### Типы токенов VK:
- **Сервисный ключ доступа** (Service Token) - для отправки уведомлений
- **Токен пользователя** - для работы от имени пользователя
- **Токен сообщества** - для работы от имени сообщества

Для push-уведомлений нужен **Сервисный ключ доступа**.

### Безопасность:
- ✅ Никогда не коммитьте `.env` в git
- ✅ Не передавайте токен в открытом виде
- ✅ Храните токен в безопасном месте
