# 🔧 Исправление двойных кликов в leads.tech

## 🎯 Проблема:
В статистике leads.tech отбивается 2 клика вместо 1

## 🔍 Причины двойных кликов:

### 1. Backend делал GET запрос на leads.tech (ИСПРАВЛЕНО ✅)
**Было:**
- При клике на МФО frontend отправляет POST на `/api/utm-track/`
- Backend делает GET запрос на ссылку leads.tech
- Frontend открывает ссылку через `window.open()` 
- **Итог: 2 клика!**

**Стало:**
- Backend только сохраняет данные в БД
- Frontend открывает ссылку через `window.open()`
- **Итог: 1 клик!**

**Файл:** `backend/api/views.py` (строка 286-291)

### 2. autoSendOnUTMChange отправляет при загрузке страницы
**Проблема:**
- `autoSendOnUTMChange` отправляет данные в `/api/arbitrage/send-to-leads-tech/`
- Это может создавать дополнительный постбэк

**Решение:** Этот метод отправляет только при наличии UTM параметров (строка 126 в useArbitrageTracker.js), это нормально для трекинга источников.

## 📊 Про "babkimankirf-of-ras-zaymer-66":

Это старая ссылка, которой **нет в текущей базе**. Возможные причины:
1. Клик пришел из старого источника (бот, старая реклама)
2. Cached ссылка в leads.tech
3. Другой источник трафика (не витрина)

**Текущие sub1 в базе:**
- `babkimankirf-of-list-*` (старые)
- `babkimankirf-of-list-open-*` (новые)

## ✅ Что исправлено:

1. ✅ Убран GET запрос из backend (views.py)
2. ✅ Теперь только frontend регистрирует клик
3. ✅ Клик регистрируется 1 раз через window.open()
