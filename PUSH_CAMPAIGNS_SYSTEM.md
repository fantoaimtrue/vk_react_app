# 📧 Система рассылок пуш-уведомлений (Bot Hunter Style)

## 🎯 Описание

Новая система рассылок пуш-уведомлений по принципу Bot Hunter позволяет:
- Создавать рассылки с несколькими шаблонами пушей
- Настраивать гибкое расписание (ежедневно, еженедельно, ежемесячно, разово)
- Автоматически отправлять пуши по расписанию
- Отслеживать историю всех отправленных пушей в отдельном блоке
- Управлять лимитами отправок

---

## 📋 Структура системы

### 1. **PushCampaign** (Рассылка)
Основная модель рассылки, содержит:
- Название и описание
- Статус (черновик, активна, приостановлена, завершена)
- Расписание (тип, время, дни недели, день месяца)
- Таргетинг (сегмент, фильтры, конкретные пользователи)
- Лимиты (дневной, общий)
- Статистику (отправлено, доставлено, ошибок)

### 2. **PushTemplate** (Шаблон пуша)
Шаблоны пушей для рассылки:
- Заголовок и текст сообщения
- Ссылка при клике
- Порядок отправки (для ротации)
- Статистика использования

### 3. **SentPush** (Отправленный пуш)
История всех отправленных пушей:
- Связь с рассылкой и шаблоном
- Пользователь-получатель
- Статус доставки
- Временные метки
- Ответ VK API

## 🚀 Использование

### Создание рассылки

1. **Перейдите в админку Django**: `/admin/api/pushcampaign/`
2. **Нажмите "Добавить рассылку"**
3. **Заполните основные данные**:
   - Название рассылки
   - Описание (опционально)
   - Статус: "Черновик" (позже активируете)

4. **Настройте расписание**:
   - **Разовая отправка**: укажите дату и время в `schedule_date`
   - **Ежедневно**: выберите `schedule_type = "daily"` и укажите время в `schedule_time`
   - **Еженедельно**: выберите `schedule_type = "weekly"`, укажите время и дни недели в `schedule_days` (0=Понедельник, 6=Воскресенье)
   - **Ежемесячно**: выберите `schedule_type = "monthly"`, укажите время и день месяца (1-31)

5. **Настройте таргетинг**:
   - Выберите сегмент (все, активные, неактивные, новые, выборочная)
   - При необходимости добавьте фильтры (город, пол, UTM source)
   - Или выберите конкретных пользователей

6. **Добавьте шаблоны пушей**:
   - Внизу страницы в разделе "Шаблоны пушей" добавьте нужное количество шаблонов
   - Каждый шаблон имеет свой заголовок, текст и ссылку
   - Порядок определяется полем `order` (шаблоны будут ротироваться)

7. **Настройте лимиты** (опционально):
   - `max_sends_per_day` - максимум отправок в день
   - `total_sends_limit` - общий лимит отправок

8. **Сохраните** и **активируйте** рассылку (действие "▶️ Активировать")

### Управление рассылками

В списке рассылок доступны действия:
- **▶️ Активировать** - активирует рассылку (меняет статус с "Черновик" на "Активна")
- **⏸️ Приостановить** - приостанавливает рассылку
- **📤 Отправить сейчас** - отправляет рассылку немедленно (независимо от расписания)

### Просмотр истории

Все отправленные пуши доступны в разделе **"Отправленные пуши"** (`/admin/api/sentpush/`):
- Фильтрация по рассылке, статусу, дате
- Поиск по заголовку, тексту, пользователю
- Детальная информация о каждой отправке

## ⚙️ Автоматическая отправка

### Настройка cron

Для автоматической отправки по расписанию добавьте в crontab:

```bash
# Каждые 15 минут проверяем и отправляем рассылки
*/15 * * * * cd /path/to/project && docker-compose exec -T backend python manage.py send_campaign_pushes
```

Или через systemd timer (рекомендуется):

```ini
[Unit]
Description=Send push campaigns
After=network.target

[Service]
Type=oneshot
WorkingDirectory=/root/vk_react_app
ExecStart=/usr/bin/docker-compose exec -T backend python manage.py send_campaign_pushes
```

### Ручной запуск

```bash
# Отправить все активные рассылки по расписанию
docker-compose exec backend python manage.py send_campaign_pushes

# Тестовый запуск (без реальной отправки)
docker-compose exec backend python manage.py send_campaign_pushes --dry-run

# Отправить конкретную рассылку
docker-compose exec backend python manage.py send_campaign_pushes --campaign-id 1
```

## 📊 Особенности

### Ротация шаблонов
Шаблоны пушей ротируются автоматически:
- При каждой отправке выбирается следующий шаблон по порядку
- Используется циклическая ротация (после последнего возвращается к первому)

### Защита от спама
- Пользователям не отправляется более одного пуша в день из одной рассылки
- Учитываются дневные лимиты
- Автоматическое завершение при достижении общего лимита

### Статистика
- Каждая рассылка ведет статистику: отправлено, доставлено, ошибок
- Каждый шаблон ведет счетчик использований
- Все отправки сохраняются в `SentPush` для детального анализа

## 🔄 Миграция со старой системы

Старая система (`PushNotification`) продолжает работать параллельно. Для миграции:

1. Создайте новую рассылку (`PushCampaign`)
2. Скопируйте шаблоны из старых уведомлений в `PushTemplate`
3. Настройте расписание
4. Активируйте рассылку

Старые данные (`PushNotification`, `PushLog`) остаются доступными для истории.

## 📝 Примеры использования

### Пример 1: Ежедневная рассылка в 10:00

1. Создайте рассылку "Утренние предложения"
2. `schedule_type = "daily"`
3. `schedule_time = "10:00"`
4. Добавьте 3-5 шаблонов с разными текстами
5. Активируйте

### Пример 2: Еженедельная рассылка (Пн, Ср, Пт в 18:00)

1. Создайте рассылку "Недельные акции"
2. `schedule_type = "weekly"`
3. `schedule_time = "18:00"`
4. `schedule_days = [0, 2, 4]` (Понедельник, Среда, Пятница)
5. Добавьте шаблоны
6. Активируйте

### Пример 3: Разовая рассылка на Новый год

1. Создайте рассылку "Поздравление с Новым годом"
2. `schedule_type = "once"`
3. `schedule_date = "2025-12-31 23:50"`
4. Добавьте шаблон с поздравлением
5. Активируйте
