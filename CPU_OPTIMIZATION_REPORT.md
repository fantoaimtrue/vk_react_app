## 📝 НАСТРОЙКИ GUNICORN

### Текущая конфигурация:

```bash
gunicorn backend.wsgi:application \
  --bind 0.0.0.0:8000 \
  --workers 2 \
  --threads 2 \
  --worker-class sync \
  --timeout 30 \
  --max-requests 1000 \
  --max-requests-jitter 50
```

### Объяснение параметров:

- `--workers 2`: 2 процесса для обработки запросов (вместо 1 по умолчанию)
- `--threads 2`: 2 потока на worker (для sync worker не используется, но указано для совместимости)
- `--worker-class sync`: Синхронные workers (подходит для Django)
- `--timeout 30`: Таймаут 30 секунд для обработки запроса
- `--max-requests 1000`: Перезапуск worker после 1000 запросов (предотвращает утечки памяти)
- `--max-requests-jitter 50`: Случайная вариация ±50 запросов (предотвращает одновременный перезапуск всех workers)
